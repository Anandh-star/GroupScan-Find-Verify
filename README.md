# 🚀 GroupScan – Find & Verify Communities

<p align="center">

**Discover • Verify • Explore Trusted Online Communities**

A modern and responsive web application for discovering trusted **WhatsApp Communities**, **Telegram Groups**, and **Discord Servers** with community verification, category browsing, trending listings, and an intuitive Admin Dashboard.

🌐 **Live Demo**
https://anandh-star.github.io/GroupScan-Find-Verify/

---

## 📖 About

GroupScan is designed to help users discover genuine online communities while avoiding fake or scam invite links.

The platform offers a clean, modern interface where users can browse communities by category, search instantly, submit new communities, and explore trending groups.

An integrated Admin Dashboard allows administrators to manage categories, review submissions, verify communities, and control platform content.
